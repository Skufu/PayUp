# Backend

## Tech

- Go + Gin
- Postgres via `pgx`
- sqlc for typed DB access
- JWT auth via `golang-jwt/jwt/v5`

## Entry points

- `backend/cmd/api/main.go`: creates DB pool, issuer, and HTTP server
- `backend/internal/server/server.go`: Gin router + route registration (v1)

## Package map

- `backend/internal/auth/`
  - `tokens.go`: issue/parse access+refresh JWTs
  - `middleware.go`: `Authorization: Bearer` parsing and `userID` context injection

- `backend/internal/handlers/`
  - `auth.go`: register/login/refresh/me/profile update
  - `groups.go`: group CRUD + invite + join
  - `expenses.go`: list/create/delete expenses with splits validation
  - `balances.go`: compute balances from expenses
  - `payments.go`: create/list/review payments; approval creates a transfer expense
  - `nudges.go`: create/list/read nudges; can trigger push
  - `push.go`: subscribe/unsubscribe push; send push helper

- `backend/internal/db/`
  - `sqlcdb/`: generated by sqlc (queries + models)

- `backend/internal/services/`
  - `upload.go`: optional Cloudinary upload support

## Database + migrations + sqlc

- Schema for sqlc: `backend/sql/schema.sql`
- Queries for sqlc: `backend/sql/queries/*.sql`
- Migrations (goose): `backend/migrations/*.sql`
- sqlc config: `backend/sqlc.yaml`

## Auth model

- Access token: JWT claim `typ=access`
- Refresh token: JWT claim `typ=refresh`
- `auth.Middleware` checks access token and sets `CtxUserIDKey = "userID"`

## Push notifications

- `SendPushToUser` in `backend/internal/handlers/push.go`
  - No-ops if `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` are missing
  - Removes dead subscriptions on `410 Gone` / `404 Not Found`

## Uploads

- Upload service is **optional**.
- When not configured, upload endpoints return `503 upload service not available`.
